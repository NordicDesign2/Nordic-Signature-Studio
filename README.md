# Nordic Signature Studio

A one-page tool for creating email signatures for Nordic Laboratories, dnalife, or both brands together, ready to paste into Gmail.

## Using it

Open `index.html` in a browser (Chrome or Edge work best), then:

1. Pick a brand: Nordic Laboratories, dnalife, or Nordic Labs + dnalife.
2. Fill in your name, job title, phone and email.
3. Optionally paste a Calendly (or other booking page) link to add a "Book a call" button. The button text can be changed.
4. Choose whether to include the confidentiality notice.
5. Optionally add event banners, either from the current campaigns list or by uploading your own (about 600×150–250px, under 1MB).
6. Click **Copy signature**, then in Gmail go to Settings → See all settings → General → Signature → Create new, paste, and save.

## Notes

- Logos and campaign banners are embedded in `index.html`, so the page works as a single file with no other assets.
- Signatures use Arial because Gmail and most other email clients strip custom web fonts.
